## 校验与恢复

在项目根目录运行，仅需 Python 标准库：

```powershell
python scripts/restore_knowledge_snapshot.py --check
```

新克隆项目尚无 `data/knowledge.db` 时，恢复默认本地数据库：

```powershell
python scripts/restore_knowledge_snapshot.py
```

工具先解压到临时目录，校验压缩包和数据库哈希、大小、完整性及条目统计，再创建目标文件。默认路径按项目所在目录解析，与终端当前目录无关。已有数据库时拒绝覆盖；可用新路径验证恢复：

```powershell
python scripts/restore_knowledge_snapshot.py --output .tmp/knowledge-v1-restored.db
```

恢复后按项目原有配置选择 `KNOWLEDGE_RETRIEVAL_MODE=managed` 和数据库路径，再通过 `启动项目.cmd` 启动。恢复工具不改私有配置，不自动启用草稿、改变审核状态或部署服务器。日常启动继续使用本机数据库；仓库快照不会在启动时覆盖它。

原始运行数据库、其他本地备份和缓存仍按原有 `.gitignore` 排除。后续本地编辑不会自动写回此快照，发布新版知识快照时应重新从数据库生成并更新清单。

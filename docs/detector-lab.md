# 检测与联合定位操作说明

入口仍是 `http://127.0.0.1:8502/`。运行项目根目录的 `start_vision_lab.ps1`，或继续使用原桌面快捷方式。在左栏“测试页面”选择“检测与联合定位”；“四模型视觉测试”保留原配置、密钥、识图/建议、四轮历史与评测含义，`app.py` 的摄影推荐流程未接入检测器。

## 环境准备与停止

检测依赖独立安装在 `.venv-detectors`，原 `.venv` 只负责 Streamlit、记录和评测。仅在明确执行准备脚本时联网安装和下载：

```powershell
.\scripts\prepare_detectors.ps1
.\start_vision_lab.ps1 -NoBrowser
```

实际锁定版本、官方契约、许可证、下载 revision/哈希和诊断见 [检测运行环境](detector-runtime.md)。默认权重位置是 `data/vision_lab/model_cache/grounding-dino-tiny/` 和 `data/vision_lab/model_cache/yolo26n.pt`，环境、权重和结果均受 Git 忽略。推理 worker 禁用 Hugging Face 网络下载和 Ultralytics 自动安装。缺环境、缺权重或设备不可用时显示对应状态；原四模型页面可继续使用。

CPU 为默认路径，精度 float32。页面提供 `cuda:0` 选择，能否运行取决于独立环境的 CUDA PyTorch 和设备诊断；不能仅凭有 NVIDIA 显卡认定 GPU 推理可用。不要把 CPU wheel 无 CUDA 的错误当作显卡故障。更改设备、权重、查询、阈值、任务或图片设置会改变缓存条件。

点击“停止空闲检测 worker”释放常驻模型。运行中的“取消当前检测任务”停止本地 worker 并跳过后续阶段，已完成结果保存。正在等待的 VLM 网络请求有独立有限超时，取消不保证撤回厂商已经接收的请求，也不保证免计费。停止 Streamlit 可在启动它的终端按 Ctrl+C；桌面隐藏启动的实例先确认8502所属进程，再只停止该实例，不影响8501主应用。

## 纯检测

1. 选择“纯检测”和一个或两个检测器，默认 CPU；无需选择 VLM、无需 API Key。
2. 上传 JPG/PNG，检查实际发送 JPEG 与原始/EXIF修正/发送尺寸。所有方法解码同一份 JPEG 字节，叠框画回方向修正后的原图。
3. 输入共同任务。Grounding DINO 可使用冻结词典映射出的英文查询，或在手工查询框每行填一个英文类别短语。手工查询来源单独保存，中文检测质量未验证。YOLO 按固定 COCO 类运行，不接收自由文本查询。
4. 点击“运行检测”。页面显示候选、框占比、模型分数、原始/过滤候选、版本/权重/设备/内部尺寸和耗时。候选检测不生成场景解释或摄影建议；框占比只表示矩形面积近似。

“模拟验证”不联网、不加载权重，候选与输入图片实际内容无关，用于检查空框、非法坐标、重复ID、多主体、整体/局部重叠、未支持类别和VLM故障流程。所有记录和导出有模拟标记，不进入真实质量统计。

## 定位对照 A/B1/B2

默认语义基线为已配置的 GLM-4.6V，依据本项目接口结构稳定性，不代表识图准确率最高。可选择其他已配置 VLM，沿用原密钥管理。**只有点击“运行对照”才向选定的真实 VLM 发送一次照片请求；不自动重试。** 实现验证不重发四轮失败单元，不自动开始十图质量实验。

| 方法 | 实际输入和解释 |
|---|---|
| A | 共享的一次 VLM 回答里的原始对象和框；严格校验，不猜像素/0～1000单位、不执行除法表达式 |
| B1 | 同一份语义 + 共同任务经 `task-english-v1` 冻结词典映射的查询，Grounding DINO Tiny 本地检测 |
| B2 | 同一份语义和任务，YOLO26n 全固定类候选再做保守类别关联；未支持目标保持 unsupported |

主对照不允许临时手工补词，也不追加第二轮 VLM 选框。独立定位提示词及其哈希随新实验保存；历史纯识图提示词含义不变。查询转换模块不接收人工框、历史复核、manifest 检查点、图片标题或文件名。

VLM 的 JSON/语义/框分别校验：框失败但独立语义合法时，B 可显式抽取语义，A 保留失败。网络/JSON/语义失败时，B1 使用共同任务词典 fallback，B2 继续本地检测，保存 detection_only 并弃权。没有可靠唯一类别/实例关联时保存 ambiguous/abstained，不按分数或面积强选。实体归属没有依据时保持 unknown；反射/画中人物等不能从一个 person 框自动确认。人工选择是单独辅助条件，自动结果保留。

共享VLM回答、检测结果可复用兼容缓存，页面标注来源result ID；每次明确运行仍生成新的run/attempt。取消“复用兼容缓存”可执行新推理，真实VLM会再产生一次请求。切换视图、填标注、点选、保存、重开、筛选与下载均不推理。运行结果中的参数已冻结，后来修改控件不改写原结果。各阶段及时落盘，检测器失败不丢失 A 或另一检测器。

## 人工标注与指标

参考框为修正方向图上的0～1 xyxy，可添加任意数量的框。每个框填写唯一gt_id、英文类别、层级、实体归属、parent_id、主目标、必需/遮挡/截断/可判定/ignore、来源与人工确认。AI预标注必须填写AI来源并保持待确认；逐框核对后才确认。“参考完整”要求全部框人工确认。人工参考从不加入推理。

在各方法评测中手工指定预测ID→gt_id的一对一对应，标记范围内预测/ignore、主目标自动/人工选对与查询/固定类覆盖，并填写独立错误条目。每条错误有独立ID，可以记录多个同类错误，包含来源、模型原话、确认、证据、严重度和原因。

| 指标 | 分母和规则 |
|---|---|
| 主体选择正确率 | 主体可判定任务；自动与人工辅助分开；失败、弃权、选错保留分母 |
| IoU | 人工合法一对一配对，同类别同层级；低IoU仍保留，列配对数/缺失数；不能单独据均值宣布更准 |
| TP/FP/FN | IoU≥0.5；整体/部件不配对、重复预测只配一个；未支持、空框、运行失败仍计必需GT漏检 |
| 有效框覆盖 | 有合法身份/层级配对框的GT / 全部可判定GT，不要求IoU≥0.5 |
| 查询/固定类支持覆盖 | 人工确认覆盖的必需GT / 全部必需可判定GT；固定类共有支持子集另列 |
| 候选可用率 | 有合法任务候选的任务 / 全部预定任务；只代表可交人工审核 |
| 完整任务成功率 | 完整参考下主体选择、必需目标框IoU、ID和必要实体归属通过的任务 / 全部预定任务；detection_only/unsupported不成功 |
| 边缘保留 | 需边缘保留任务中，各必需框支持面积≥95%且IoU≥0.5；仅矩形覆盖 |

参考未完整或候选尚未人工评测时，质量指标为未知/未评测。运行失败影响流程可用率，照片内容未知不自动判识别错误。范围外合法背景候选不因未标注背景而自动成为FP；任务误检需明确标为范围内。实体unknown可通过人工对应评估几何，必要实体标签未知仍不能算完整任务通过。

耗时区分模型加载、预处理、推理、后处理、共享VLM及总等待；缓存记录来源与原耗时，不能把原耗时当本次热推理。共享VLM费用只计一次；缺单价/用量/账单时费用未知，本机计算成本未知，完整组合费用不写成0。

## 保存、重开与导出

新记录保存在 `data/vision_lab/detector_experiments/runs/`，与旧v1历史独立。阶段记录自动保存；照片副本仅在主动勾选并点击保存时落盘，为去EXIF的修正图。没保存照片也能重开文字结果；重传相同哈希原图恢复叠框。

JSON包含完整来源和阶段，CSV保留方法/状态/真实模拟/开发验证/自动人工条件、错误ID和指标分母。可按阶段、模型、任务、图像、错误类型和确认状态筛选。密钥、请求头、完整base64不进入记录或导出；CSV对公式前缀转义。

`scripts/prepare_detector_pilot.py` 可准备独立 `detector_pilot10_v2` manifest：开发 P02/B02/D03，验证 P06/D07/P09/D13/B03/C03/D16。图片已在前期看过，不能称完全盲测；不复制旧AI复核为GT，不运行质量实验。完成独立人工参考后，在页面明确逐图运行。

## 检查与故障

```powershell
$env:TEMP = Join-Path (Get-Location) 'tmp'
$env:TMP = $env:TEMP
.\.venv\Scripts\python.exe -m pytest -q --basetemp tmp/pytest-detector-check
.\.venv\Scripts\python.exe -m ruff check .
.\.venv\Scripts\python.exe scripts/detector_smoke.py
```

缺权重：执行准备脚本检查官方下载与清单，不在刷新时下载。网络受限：保留模拟与其它页面能力，具体准备错误见运行环境说明。坐标错误：保留raw_candidates与转换依据，不静默截断。无框：可能查询/阈值/类别不支持或检测漏检，不能自动宣布图中无目标。加载超时：调有限超时后明确新运行，停止worker会失去热缓存。原环境不安装torch/transformers/ultralytics。

# 视觉模型测试工具实施计划

**Goal:** 在现有项目中交付独立运行、可离线评测的 Streamlit 视觉实验工具。
**Spec:** `../../视觉模型测试窗口-实施提示词.md`（用户提供的完整规格）。
**Architecture:** 独立 `vision_lab_tool` 包负责数据模型、图片、协议、运行、评测和本地存储；`vision_lab.py` 仅为页面入口。图片与人工标注隔离，调用结果按 run_id / result_id 持久化；重跑只渲染已有结果。
**Tech Stack:** Python 3.11+、Streamlit、Pydantic 2、Pillow、httpx、pytest、ruff。

## 约束
- 保留 app.py、原主流程及知识库；不批量跑图、不发布云端。
- 默认 15 MB、EXIF 方向统一、所有模型使用同一 JPEG；坐标严格校验。
- 无密钥启动；真实请求仅由运行按钮触发，不自动重试。
- 纯识图请求不包含标注、目标、器材、EXIF、历史回答；建议上下文单独开关。
- 图片默认不落盘；配置只保存密钥来源变量名，输出全面脱敏。
- 模拟不进入真实质量排行，未标注不计准确率，币种分别累计。

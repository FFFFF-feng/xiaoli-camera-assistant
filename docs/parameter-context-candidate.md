# 参数请求精简候选（默认关闭）

本轮E2三例的最长支路是parameters，平均68.609秒、首内容前57.991秒。这些时间不能区分服务商排队、网络和内部处理；不据此给出原因或提速承诺。

`OpenAICompatibleRecommendationAdvisor(settings, compact_context=True)` 是独立显式候选；所有正常调用继续默认False。未修改模型、thinking、图像、输出字段、并行关系或手机分支。

候选保持原规范指令、完整用户请求、场景（含对象/不确定性）、器材的null/false边界、C的共享事实与物理约束。只压缩Schema JSON空白，并对完全相同的知识记录共用全文；保留原引用位置、document_id、标题、内容、来源和metadata，不合并不同出处。先验不能证明这种提示格式改变在真实模型上质量等价，因此不默认启用。

离线审查通过实际advisor加fake request_json和socket拒绝捕获内存payload。三个E2输入由上传manifest与结果重建，内部effective_request规范化未单独留存，不宣称逐字复原线上请求。度量仅字符、UTF-8字节、字段、重复值和Schema，不保存敏感payload。

第一版额外JSON包装使三例各增加157字符，已保留为失败候选；精简后仅各减少79字符。这个幅度不足以支持57.991秒等待将显著改善的推断。非空知识重复另用明确标记的合成反例验证，无原检索数据被编造。

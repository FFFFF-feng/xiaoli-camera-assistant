# 小栗 · 随身相机工坊

更新：2026-10-17

## 设计依据

使用用户指定的 [distinctive-ai-design](https://github.com/houxin0010/distinctive-ai-design) 流程。围绕摄影初学者的核心任务：放入现场照片，描述期待的效果，取得可用于试拍的建议。

在摄影杂志、取景器工具、摄影搭子手帐三个方向中，选择有温度的摄影搭子方向，再以实体相机的材质和光学动作建立交互个性。采用奶油白、深棕和铜橙；以用户提供的吉祥物为参考，使用经用户确认的四个动作版本。

## 关键实现

- 首页采用吉祥物介绍区与拍摄工作区，桌面双栏，手机单栏。
- 拍摄、建议、记录、连接分别使用举相机取景、讲解构图、翻看相册、操作手机与电脑的动作。透明素材以无损 WebP 保存于 `assets/mascot/`，通过 `MascotArt.vue` 统一完整展示角色及道具；Streamlit 入口沿用用户原图。
- 铜色主按钮有细密纹理、斜面高光、底座与按压位移；辅助操作采用奶油色实体键。
- 指针光泽与微倾斜由单个委托事件监听器处理，按动画帧合并更新，仅在精细指针且允许动态效果时启用。
- 自绘 SVG 光圈用于开始按钮与分析状态。图片预览有短暂的显影过渡；分析中有扫描反馈。
- 原生 View Transition API 用于光圈式内容转场；页眉与导航有独立的快照名称。连续点击以最后一次请求为准；旧浏览器使用 Web Animations API 淡入回退。
- 设备设置在支持 intrinsic size interpolation 的浏览器中平滑展开。
- 尊重系统减少动态效果设置，切页后将键盘焦点移到标题，保留键盘焦点提示。
- 动画和材质没有新增第三方运行依赖。

## 验证与边界

- Vue 类型检查及生产构建通过。
- 合并远端多图功能后，现有 28 项前端测试通过；页面与网关的 10 项 Python 测试已在界面改造阶段通过。
- 浏览器实查了首页、建议空状态、设备切换、快捷效果输入、连续切页和手机窄屏。
- 规则演示环境已验证选图预览、上传授权、生成结果的完整流程。没有使用云模型验证建议质量。
- 动效版本在可见浏览器中确认使用原生转场，并观察到动画运行状态。截图评审为自查。
- 尚未实测 Android 真机帧率、各浏览器旧版本及系统减少动态效果的切换；已提供兼容分支。

运行截图保存在本机 `output/design-review/`；该目录按项目既有规则不纳入 Git。

## 本地预览

前端开发预览：在 `mobile` 目录执行 `npm run dev`。默认端口被占用时，可使用 `npm run dev -- --port 5174`。

完整规则演示：先在 `mobile` 目录执行 `npm run build`，再从项目目录运行 `scripts/start_web.py --demo`。已有体验码与网关配置仍按项目原有流程使用。

# 小栗 Android 安装包交付说明

本次同步 main ca2323e 中队友最新的构图、物体边界和分析报告优化，使用已有 Capacitor 工程构建 Android debug APK。不部署或修改线上服务器，不向安装包写入模型密钥、连接令牌、个人照片或本地知识数据库。

## 安装与使用

安装 `xiaoli-camera-assistant-20261019-debug.apk`。最低 Android 7.0，仍依赖设备上可用的 Android System WebView。这是测试签名版本，不是应用商店正式发行包。若手机已装旧包且签名不同，不会自动卸载；先备份需要的本机记录，再决定是否卸载旧版。

手机端包含界面、系统相机入口、构图绘制和配色逻辑；模型与知识检索在后端。由于本轮不部署新服务器，推荐用电脑局域网服务配合演示：

1. 完整项目中安装依赖 `python -m pip install -e ".[mobile]"`。
2. 双击根目录 `启动手机服务.cmd`。该入口加入 `--local-config`，复用与本地新版网页一致的模型配置和智谱代理策略，避免手机后端与网页模式不一致。私有文件不会被修改或打印。
3. 电脑与手机连接同一可信 Wi-Fi。运行 `ipconfig` 找到电脑的IPv4地址。
4. App底部“连接”填写 `http://电脑IPv4:8000`，不要填写127.0.0.1、8080、8501或8502。
5. 从 `.launcher/mobile-access.json` 本地复制手机令牌。若明确配置 `MOBILE_API_TOKEN`，使用配置值；不要填写模型API Key。
6. 点击“保存并测试连接”。确认页面分析模式；真实模式要有有效模型配置，`--demo` 强制规则演示。

命令行的等价入口为 `python scripts/start_mobile_api.py --host 0.0.0.0 --local-config`。没有配置云模型时不会伪装成云分析。HTTP只用于可信局域网；本轮不修改防火墙或开放公网端口。独立服务地址仅在已有兼容接口与有效 HTTPS 证书时配置，不绕过证书校验。

## 重建与版本核对

已有工具环境中运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build_android.ps1 -SkipNpmInstall`。如果前端依赖没有安装或锁文件变化，先按工程说明安装；不能跳过构建继续使用旧APK。

本次 APK 内应用版本仍沿用工程的0.1.0、versionCode 1；交付文件以日期及SHA256区分构建，不把版本号当成内容新旧的唯一依据。包名 `com.xiaoli.cameraassistant`。本机签名未重新生成。更新是否允许覆盖安装以手机的签名校验结果为准。

配套后端源码包不含Python、Node、Android SDK、私有配置、数据库及照片，需要按 README 安装运行环境。正式内容库在原电脑独立保留，没有为了交付擅自公开数据库。

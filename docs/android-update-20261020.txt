小栗摄影助手 Android 0.2.0 更新说明（2026-10-20）

一、安装
将 xiaoli-camera-assistant-20261020-v0.2.0-debug.apk 发送到安卓手机，点击安装并选择“更新”。
包名保持 com.xiaoli.cameraassistant，versionCode 从 1 升到 2；交付脚本会核对新旧包签名一致。
请不要先卸载。正常覆盖更新应保留连接配置和本机历史，但仍建议先导出重要记录。
若系统提示签名不一致，请停止安装，核对手机原包来源，不要为安装新版直接删除旧数据。
最低 Android 7.0，依赖可用的 Android System WebView。这仍是测试签名安装包，不是商店发行版。

二、本次变化
打入当前最新界面、构图反馈与三分线显示；增加手机型号搜索及主摄、超广角、长焦等后置镜头选择。
相机镜头按卡口和已知画幅筛选；选中有明确规格的镜头，可联动实际焦距、标称光圈和等效视角。
设备数量由所连接的后端及已发布知识决定，不把数据库打入 APK；缺失或未核验的能力不猜填。
当前线上后端有 514 款已知手机、1638 组镜头参考和 8301 条已发布知识；其他后端可能不同。

三、连接方式与限制
App 保留“连接”页手动填写服务根地址和手机连接令牌，已有配置在正常覆盖安装后继续保留。
模型 API Key 不是手机令牌；本安装包不包含任一种私有密钥、连接令牌、个人照片或知识数据库。
可信同一 Wi-Fi 演示：电脑启动“启动手机服务.cmd”，App填写 http://电脑IPv4:8000，
从电脑的 .launcher/mobile-access.json 本地读取手机连接令牌（若显式配置 MOBILE_API_TOKEN 则用配置值）。
公网须使用有效可信 HTTPS 证书且主机名匹配的服务地址，并由管理员提供该服务器接受的手机令牌。
现有公网网页 https://115.29.241.181/ 可以在浏览器使用；这不等于 APK 已通过证书与令牌连接验证。
本次仅生成本地新版 APK，没有同步服务器手机令牌、修改服务器证书、移除鉴权或更新 GitHub 附件。
若当前无法拿到有效公网连接配置，可先用局域网后端，或用手机浏览器打开网页版。
不要绕过证书校验，不要把手机令牌公开提交到 GitHub 或写进分享包。

四、验证范围
已构建并验证 APK 签名、版本递增、与旧交付包的签名一致性、内置资源与当前前端构建一致性，
并扫描禁止交付文件及本地已知私密配置。构建结果不等于真实手机和实际拍摄验收。
安装后依次检查：保存并测试连接 → 型号/镜头选项 → 非敏感照片上传 → 建议/构图 → 历史与导出。
本包不自动打开管理工作台；知识导入仍由电脑或受控管理入口完成。
知识库检索与模型分析仍在后端执行；本次不更改手机参数建议的现有规则处理链路。

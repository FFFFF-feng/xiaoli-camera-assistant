# 四模型快捷配置与本机密钥保存验证

2026-10-11 增量交付，满足用户固定四模型、简化配置、长期本地保存 Key 及界面说明的请求。

## 改动
- `configuration.py`：四个稳定配置 ID、官方模型 ID/地址/Chat 协议预填、120秒与4096输出上限、既有配置保留；本机 Key 优先于环境变量。
- `credentials.py`：Windows 当前用户 DPAPI 加密、原子替换、留空保留/删除、损坏文件保护；不是机器范围加密，不依赖第三方库。
- `ui_credentials.py`：三个专用密码框，两个豆包共用方舟 Key，保存后清空、不回显，重开自动读取。密码框刷新使用新控件身份，避免前端残留旧值。
- `ui.py`：常用四模型与模拟/其他配置分开选择，高级项收起；加入模式与图像设置的通俗解释。临时Key独立保存在会话中，盲评或隐藏控件不改变调用账号。
- `ui_config.py`：显式保存后解除配置读取失败保护。自动预设迁移不会覆盖损坏或不兼容的旧配置文件。
- `README.md`、`vision-lab.md`：更新使用步骤与密钥优先级；桌面入口和原 `app.py` 不变。

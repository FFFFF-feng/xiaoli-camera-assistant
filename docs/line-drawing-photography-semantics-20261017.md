# 摄影文字一致性修复记录

本记录覆盖摄影文字与器材、用户目标、二维构图表示之间的一致性。四图新一轮真实完整上传、画面质量和完整耗时以本次总验收报告为准；这里的冻结结果重放不能代替真实完整上传。

## 已验证的原因

- 基线 R50 能力目录已经明确 `ibis_stops=0`，问题不在型号匹配。参数与构图提示词收到该目录，但原本地校验只处理参数数值、部分曝光因果与精确距离，没有检查防抖能力文字及快门与取景稳定性的错误关系。保存的 02 结果可重现这些文字问题。
- 06 的用户目标明确保留暖色，原参数分支与构图分支没有共用白平衡目标或本地汇合检查；参数输出可以把钨丝灯预设解释为保暖，而构图另给一个预设。图片呈现暖色不等于确认现场灯具种类。
- 08 原校验允许一份推荐同时要求偏置三分与中轴对称，没有明确区分原构图评价、条件式替代方案与同一推荐中同时成立的承诺。
- `generic_unknown` 演示目录含保守默认值；对未知实际器材，不能把此类默认 `ibis_stops=0` 当作已确认没有 IBIS。共享事实现在将所有 `generic_*` 的该能力视为未知。

## 代码处理

- 新增不可变 `PhotographyFacts`，在流水线并行分支启动前，从用户请求、已规范化运动状态、机身目录生成一次；使用现有独立 `copy_context` 传给两分支。用户明确的白平衡目标与支撑条件优先，暖色成像不作为灯具类型证明。
- 参数和构图生成提示词读取同一事实。保暖目标统一为自动白平衡试拍、锁定并按预览向暖微调；中和偏色采用另一个受控目标。未知机型不推断机身防抖；R50 不指导依赖 IBIS；机身防抖不能代替凝固主体运动所需快门。
- 新的本地语义规则检查明确的肯定因果与能力声称。否定句、能力未知说明、支持时的条件式指导，以及说明对称代价的居中/三分比较有独立正例；并非仅按危险关键词删除文字。修正以局部语句为单位，保留同一建议中的对焦等独立动作，并明确记录校验说明。
- 确认同一推荐中偏置三分与中轴对称冲突时，先以原取景为比较基准并重置意图，再计算布局。旧协议已经带来的不一致图形不能靠改文字证明正确，予以移除。真实侧移的视差、遮挡收益写为现场观察与试拍，不能由二维推荐图证明。
- 连续场景在本地布局前强制四项意图为 `keep`，同步去除偏置、独立移动和缩放的文字承诺，说明保留原取景及三分代价；不编造缺失意图、画外内容或新机位。
- `composition_ready`、构图中间快照、最终汇合均接受同源本地检查。没有增加云调用，没有改变参数/构图并行、轮廓与意图的依赖顺序、连接复用、历史写入、缓存或事件计时流程。

## 验证与限制

最初五个具体回归用例在修改前全部因目标断言失败：快门因果、R50 IBIS、保暖白平衡、三分/对称、二维视差承诺。新增自动用例还覆盖未知能力的有/无两种错误推断、正确否定与条件句、共享事实同实例且不可变、连续场景过滤后必填列表与序列化、重复校验幂等，以及含白平衡修正的 `ready == final`。

离线定向命令：`pytest -q tests/test_photography_facts.py tests/test_validator.py tests/test_pipeline_parallel.py tests/test_composition_intents.py tests/test_composition_advisor.py`。在本机使用工作区内独立 `--basetemp`，避免受限系统临时目录的创建错误。完整测试与启动入口检查由总验收统一执行。

最终定向结果：213 项通过，耗时 16.60 秒；其中新增摄影事实回归 46 项。`git diff --check` 通过。说明字段（goal、意图诊断、取景计划与分镜说明）的摄影关系也接受同一检查，回归验证修正不改变来源几何。独立复查发现旧规则会误删“提高快门速度降低抖动/增加稳定性”等正确方向；新增 8 项方向与否定句回归，先确认 3 项正例失败，再按“降低稳定性或增加抖动”为错误关系修复。

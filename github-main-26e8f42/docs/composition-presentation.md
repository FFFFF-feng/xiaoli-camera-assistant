# 构图展示模式与验收

本轮将实际变化很小、连续场景和无法安全补全的贴边主体归为 `source_preserving`：主画面显示原图、取景参考框、边缘余量和现场动作，标注“未模拟新机位”。有明显变化时继续显示“推荐构图示意”，旁边展示现场操作卡。

`layout_presentation.py` 集中管理模式判断。初始阈值为缩放 6%、画面中心位移 4%、主体中心位移 4%、主体宽高占比变化 5 个百分点。位移使用归一化坐标中的欧氏距离，所有主体都必须低于阈值，且画幅没有变化，才判为近似恒等变换。贴边保护使用 1% 原图余量或现有像素截断证据；接近边缘不伪装成已经确认的截断证据。

连续场景始终保留原取景。通过主体完整性与比例检查且确实改变画幅的裁切保留 `crop_projection`。两条后端路径都保留所有主体的统一变换，并通过调试日志记录最终变化量、判定时的变化量和展示模式。

新增可选 `target_frame` 为原图坐标中的 `[x1,y1,x2,y2]`，当前保留模式输出 `[0,0,1,1]`，明确表示原图已知范围的取景参考框，不声称提供新的机位视野。`observed_frame` 仍表示原图在示意画幅中的覆盖区域，两者不混用。历史数据缺少新字段时可以继续读取，前端使用完整原图范围作为参考。

现场操作卡复用 `proposal.actions`、`board.changes`、`distance_instruction` 和 `framing_plan`。箭头只来自已有明确机位动作，不根据主体在二维画面中的位移推测相机移动方向。余量按原图中所有主体的联合外框估计，并提示其中可能包含其他景物。

主构图组件已移除推测延伸背景入口和调用；框内没有绘制的地方不代表现场留白。AI 构图预演的调用、默认关闭状态、用户主动触发方式和原图对照保持原样。模型、分析主链路、启动端口及部署方式没有变化；启动 CMD 仅同步了展示功能提示。

## 离线验收样例

运行 `.venv\Scripts\python.exe scripts\build_composition_acceptance.py` 可从本地求解器重新生成四种合成场景：近似恒等变换、明显左移并放大、主体接触左边缘、连续场景。样例位于 `mobile/tests/fixtures/composition-presentation.json`，含原始测试图片与真实求解器输出，不调用任何模型。

在 `mobile` 中运行 `npm run dev`，打开 `/tests/fixtures/composition-acceptance.html` 即可检查四类页面。前三类对应用户要求的三组验收，连续场景另列。该页面仅作为开发验收入口，不进入生产构建。

- 保留模式应以原始测试图为主，显示参考框、余量和动作卡，不显示重描的推荐线稿；贴边样例需显示红色接触标记和后退提示。
- 明显变化样例应显示向左且放大的统一轮廓，保留真实性说明、操作卡和原图对照。
- 连续场景应展示完整原图，不补画画外结构，并提示现场核对透视、遮挡和背景。
- 原图缺失或加载失败时只提示补充原图并保留文字动作，不回退成一张“新的推荐图”。

合成样例只验证展示分支，不能替代真实照片的识别质量和现场效果验收。初次浏览器访问本地验收页超时；后续定位到受限执行环境禁止本机套接字访问（Windows 错误 10013），改用正常本机权限运行标准启动入口后，浏览器已能访问网页并显示“云模型”。构图展示分支、动作卡、缺图回退和默认不触发 AI 预演通过 Vue 实际组件渲染测试，完整构图页面仍需真实照片视觉验收。

## 验证

前端执行 `npm test` 与 `npm run build`（含 `vue-tsc --noEmit`）。后端覆盖布局求解、旧路径、边缘证据、连续场景、协议兼容与构图主链路。启动器单独顺序测试，并执行 `启动项目.cmd --check`。若系统临时目录不可写，应将 pytest 临时目录设为项目内新建的独立目录。

本次验证结果：布局及兼容相关测试 109 项、构图主链路测试 77 项、启动器测试 38 项全部通过；前端测试 115 项全部通过；类型检查、生产构建和 `启动项目.cmd --check` 通过。


## 真实模型链路验证（2026-10-20）

使用本机配置的智谱 GLM（glm-4.6v）经本地网页 API 提交项目自带的小熊猫插画：3 次模型请求全部完成，服务端完整分析约 98 秒，返回拍摄参数和 1 个构图方案。识别、轮廓提取、构图意图与布局计算全部通过，布局为 `source_preserving`，实际返回的 storyboard、framing_plan 通过前端校验。测试使用插画，不替代真实照片效果验收；构图状态 `unverified` 仍表示现场效果待确认。AI 图像预演未触发。密钥、私有配置、请求结果及截图仅保存在本机，不进入源码提交。
